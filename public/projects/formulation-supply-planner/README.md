# Formulation Cost Optimisation & Supply Chain Planner

A private Excel/VBA tool for inventory-constrained supply planning and cost optimisation.

[View the anonymised workflow showcase](https://charlie-qi394.github.io/charlie-qi-portfolio/#project/formulation-supply-planner)

## What the tool does

- Provides independent supply-availability and cost-optimisation workflows.
- Forecasts ingredient demand for planned production volume.
- Respects stock availability and privately configured formulation requirements.
- Compares original usage, optimised usage and differences.
- Reports cost impact per MT and for the planned volume.
- Keeps five scenario snapshots for compact comparison.

## Confidentiality and IP

The Excel workbook, VBA source, ingredient dataset and detailed screenshots are not distributed in the current public version. Ingredient names, compositions, quantities, prices, stock, target limits and calculated results are withheld.

The portfolio uses a generic, anonymised interface preview with Material A/B/C and no formulation or commercial values. Its buttons demonstrate layout and navigation only; they do not run an optimiser.

Inventory is manually entered in the private tool today. Live inventory feeds and stock-movement-driven replanning are a future extension, not implemented integrations.
